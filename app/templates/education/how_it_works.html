How Our Security Works

A deep dive into the hybrid cryptographic architecture protecting your files.

The Hybrid Encryption Flow

1. Raw File
User selects file
2. AES-256-GCM
Generate random file key & encrypt payload
3. RSA-OAEP
Wrap AES key using Recipient's Public Key
4. RSA-PSS
Sender signs hashes for authenticity
AES-256-GCM (Symmetric Encryption)

We use AES (Advanced Encryption Standard) in GCM (Galois/Counter Mode) to encrypt the actual file contents. Why symmetric? Because it's fast and efficient for large data. GCM is an authenticated encryption mode, meaning it guarantees both confidentiality and integrity—it detects if the ciphertext is tampered with.

RSA-OAEP (Asymmetric Encryption)

Asymmetric encryption is too slow for large files. Instead, we use a 2048-bit RSA key pair to protect the AES file key. The AES key is encrypted (wrapped) using the recipient's Public Key via OAEP padding scheme, ensuring only their Private Key can unwrap it.

SHA-256 (Hashing)

A cryptographic hash function acts like a digital fingerprint for your file. We calculate the SHA-256 hash of the file. If even a single bit of the file changes, the hash completely changes. This allows us to verify data integrity upon download.

RSA-PSS (Digital Signatures)

To prove who uploaded or shared the file (Non-Repudiation), the sender creates a digital signature by encrypting the file's hash with their Private Key. Any recipient can verify this signature using the sender's Public Key.

Argon2id (Password Hashing)

We do not store your passwords. We use Argon2id, the winner of the Password Hashing Competition, to securely hash your password with a unique salt. It is designed to resist both GPU cracking attacks and side-channel attacks.

Key Differences Summary
Concept Reversible? Keys Required Primary Purpose
Symmetric Encryption Yes 1 (Shared Secret) Confidentiality of Data
Asymmetric Encryption Yes 2 (Public/Private Pair) Key Distribution
Hashing No (One-way) 0 Integrity Verification
Digital Signing No (Verify only) 2 (Sign with Private, Verify with Public) Authenticity / Non-repudiation
